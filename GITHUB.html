Презентация: GitHub Pages и хостинг

Что такое GitHub Pages?

GitHub Pages — сервис для размещения статических сайтов прямо из репозитория GitHub.

URL формата: https://username.github.io/repo-name/

Пошаговое создание сайта

  1. Создать репозиторий на GitHub
  2. Добавить файлы сайта (index.html, style.css)
  3. Перейти в Settings → Pages
  4. Выбрать ветку main/master
  5. Открыть ссылку сайта

Пример HTML-кода

<!DOCTYPE html>
<html>
<head>
<title>Мой сайт</title>
</head>
<body>
<h1>Привет, мир!</h1>
</body>
</html>

Альтернативные хостинги

Помимо GitHub Pages можно использовать:

  • Netlify
  • Vercel
  • Firebase Hosting
